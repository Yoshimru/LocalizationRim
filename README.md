# Поиск русификаторов RimWorld

Программа проверяет активную сборку RimWorld, определяет встроенный русский язык и уже установленные языковые пакеты, ищет недостающие переводы в Steam Workshop и может установить их автоматически.

## Запуск

Откройте двойным кликом:

`Запустить поиск русификаторов.vbs`

Окно консоли при запуске не появляется. Дополнительные программы и RimSort не требуются.

## Поиск переводов

1. Нажмите **«Загрузить активную сборку»**.
2. При необходимости выберите категорию или используйте текстовый фильтр.
3. Нажмите **«Искать для отмеченных»** или **«Проверить всю сборку»**.
4. Если найдено несколько вариантов, выберите подходящий в выпадающем списке.

При расчёте рейтинга переводы с поддержкой RimWorld `1.7` и `1.6` получают дополнительный приоритет. Наличие обеих актуальных версий даёт максимальный бонус.

Базовая игра и официальные DLC исключаются из поиска. Один языковой пакет может покрывать сразу несколько связанных модов — это учитывается автоматически.

## Установка переводов

1. Отметьте найденные переводы в колонке **«Выбрать»**. Кнопка **«Отметить все»** выбирает их все.
2. Нажмите **«Установить выбранные»**.
3. Дождитесь окончания подписки и обновления списка модов.

Кнопка **«Выбрать версии 1.5–1.7»** автоматически выбирает для каждого мода лучший перевод с поддержкой `1.7`, затем `1.6`, затем `1.5`, и отмечает его для установки. Варианты без подходящей версии пропускаются.

Программа подписывается на выбранные страницы Workshop, ждёт загрузки файлов, создаёт резервную копию `ModsConfig.xml` и добавляет переводы в активный список. RimWorld во время установки должен быть закрыт.

Если перевод уже скачан, но выключен, нажмите **«Отметить неактивные переводы»**, затем **«Активировать переводы»**. Повторный поиск и загрузка не требуются: программа добавит установленные языковые пакеты в `ModsConfig.xml` и обновит список.

## Машинный перевод

Для строк **«Перевод не найден»** доступна кнопка **«Машинный перевод»**:

1. Отметьте нужные строки в нижней таблице.
2. Откройте **«Настройки»** и выберите Google, Yandex или AgentRouter.
3. Для AgentRouter укажите OpenAI-compatible Base URL, модель и API-ключ.
4. Нажмите **«Машинный перевод»**, подтвердите список и запустите RimWorld.

Программа активирует установленный `Auto Translation`, ограничивает его выбранными модами и настраивает провайдер. Оригинальные папки Workshop не изменяются. API-ключ приложения хранится в `config/settings.json` в зашифрованном DPAPI-виде; конфиг самого Auto Translation получает ключ в формате, необходимом этому моду.

## Категории

- **Нужен поиск** — русский язык не найден.
- **Русификатор активен** — перевод уже включён.
- **Русификатор установлен** — перевод скачан, но не включён.
- **Встроенный русский** — перевод находится внутри оригинального мода.
- **Русификаторы** — сами языковые моды.
- **Локализаторы других языков** — отдельные китайские, корейские, японские и другие языковые пакеты. Они маркируются отдельно и не участвуют в поиске русификаторов.

Результаты можно сохранить через кнопку **«Экспорт...»** в HTML, JSON или CSV.

## Действия с модами

- Двойной щелчок по строке открывает страницу мода в Steam Workshop.
- Правая кнопка мыши открывает меню: открыть Workshop, удалить мод с отпиской, убрать только из активного списка, скопировать название или package ID.

При удалении из активного списка подписка сохраняется. При удалении с отпиской мод также удаляется из `ModsConfig.xml`, а Steam удаляет его файлы Workshop. Перед изменением конфига создаётся резервная копия.

## Структура

- `src/` — интерфейс приложения;
- `src/modules/` — поиск, Steamworks, настройки и машинный перевод;
- `src/helpers/` — изолированные фоновые операции;
- `bin/` — локальные Steamworks DLL;
- `config/` — настройки приложения;
- `runtime/` — отчёты и временные данные.
