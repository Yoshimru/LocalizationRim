# Поиск русификаторов RimWorld

Программа читает активную сборку из `ModsConfig.xml`, проверяет все установленные папки Steam Workshop, определяет встроенный русский язык и уже скачанные русификаторы, а затем ищет недостающие переводы.

## Запуск

Откройте двойным кликом:

`Запустить поиск русификаторов.bat`

Ничего устанавливать не нужно: используется стандартный Windows PowerShell 5.1.

## Как пользоваться

1. Нажмите **«Загрузить активную сборку»**. Пути к конфигу RimWorld и Workshop определяются автоматически.
2. Программа отметит моды, которым нужен поиск. Можно изменить отметки или отфильтровать список.
3. Нажмите **«Искать для отмеченных»** либо **«Проверить всю сборку»**.
4. Дважды щёлкните ссылку в нижней таблице, чтобы открыть страницу Steam Workshop.
5. Кнопка **«Экспорт...»** сохраняет список в HTML, JSON или CSV.

Список автоматически разделяется на категории: нужен поиск, активный русификатор, установленный, но не активный русификатор, встроенный русский, сами языковые моды и отсутствующие файлы. Категории можно выбирать в выпадающем фильтре.

Отдельный мод можно добавить по ссылке Steam Workshop или числовому ID. Если он не установлен, название и версии будут загружены через Steam API.

## Что означают статусы

- **Русский встроен** — в папке оригинального мода найдена `Languages/Russian`.
- **Есть перевод** — в активной сборке найден отдельный русификатор, связанный с оригиналом.
- **Русификатор** — сама строка является языковым модом.
- **Не найдено** — автоматический поиск не дал достаточно точного совпадения; остаётся ссылка **«Ручной поиск»**.

Оценка совпадения учитывает название оригинала, `packageId`, ссылку на оригинальный Workshop ID, тег `Translation` и упоминание русского языка. Это уменьшает количество ложных совпадений, но перед подпиской всё равно стоит проверить описание страницы.

## Командная строка

Вся активная сборка:

```powershell
powershell -ExecutionPolicy Bypass -File .\RussifierFinder.ps1 -Cli -OutputPath .\report.html
```

Один или несколько модов:

```powershell
powershell -ExecutionPolicy Bypass -File .\RussifierFinder.ps1 -Cli -WorkshopId 2988200143,1127530465 -OutputPath .\report.json
```

Параметр `-IncludeWithRussian` заставляет искать переводы даже для модов, где русский язык уже найден.
